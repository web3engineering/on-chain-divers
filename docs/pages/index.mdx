# OnchainDivers indexer examples

This site is the executable guide to querying OnchainDivers data. Every example
shown here has a corresponding source file in the repository and is run during
the documentation build.

## Data products

| Product | Structured data | Raw workflows |
| --- | --- | --- |
| [Solana](/solana/) | Pump.fun, PumpSwap, Raydium, Meteora, Jito and helper tables | Transfers, top-ups, reserve accounting and creator migration analysis |
| [Polymarket](/polymarket/) | On-chain fills plus event and market metadata | Capture discovery, download and CLOB snapshot/delta replay |
| [HyperLiquid](/hyperliquid/) | Fills, fulfilled orders, wallets and positions | Recovery-file discovery, download and order-level book replay |
| [Robinhood Chain](/robinhood/) | Tokens plus Uniswap v3/v4 pools and swaps | Pool discovery, protocol comparison and EVM transaction context |
| [Fees API](/fees-api) | Aggregate transaction, priority, tip and trading fees | Validated JSON client |

The flagship [Bitcoin five-minute cross-venue reconstruction](/bitcoin-5m-cross-venue)
combines the Polymarket metadata and CLOB archives with HyperLiquid's raw BTC
perpetual book in one reproducible analysis.

## Why the examples stay current

The static site has a strict build gate. Before the pages are compiled, Python:

1. compares each live database with its published table whitelist;
2. requires a description for every published column;
3. executes all ClickHouse examples with bounded time windows;
4. checks PumpSwap reserve and fee identities;
5. scans, copies and reconstructs deterministic raw order-book captures;
6. downloads a Bitcoin five-minute market around UTC now minus 24 hours,
   assembles both raw books, and renders the synchronized analysis chart; and
7. validates the configured fees service.

If any of those checks fails, no site image is produced.

### indexer3_sol_fundings

One row per sender/receiver pair in a successful transaction where wallets lost and gained SOL, from the indexer3 server (UTC). Receiver gains below about 0.09 SOL and program accounts are left out. No signature column; identify the transaction by slot and tx_idx. With several senders or receivers each row repeats the full loss and gain, so filter n_src = 1 AND n_dst = 1 for exact pairs and never sum dst_increase over rows with n_src > 1.
